# bazel_rules_openxc7

Bazel rules for AMD/Xilinx 7-series FPGAs built with the open toolchain:
Yosys, nextpnr-xilinx, Project X-Ray and openFPGALoader.
The rules take the same shape as
[rules_vivado](https://github.com/filmil/bazel_rules_vivado), so a project
can move between the two by changing a `load` line.

Work in progress.
